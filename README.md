# Vagon boshqaruvi

Android Studio loyihasi (Kotlin + Jetpack Compose).

## Ishga tushirish
1. ZIP faylni oching.
2. Android Studio -> Open -> `VagonBoshqaruvi` papkasini tanlang.
3. Gradle Sync tugashini kuting.
4. Run tugmasini bosing.

## Demo admin
- Login: `admin`
- Parol: `VagonAdmin2026!`

Birinchi kirgandan keyin admin parolini yangilang. Oddiy ro'yxatdan o'tgan foydalanuvchilar Xodim rolida yaratiladi; admin ularni Rahbar roliga o'tkazishi mumkin.

## Eslatma
Hozirgi versiya ma'lumotlarni qurilmaning lokal SharedPreferences xotirasida saqlaydi. Bir nechta telefonda bir vaqtda ishlash uchun keyingi bosqichda server/Firebase sinxronlash qo'shilishi kerak. Parollar ochiq matnda emas, SHA-256 xesh ko'rinishida saqlanadi.
